# 1.0.3 — оптимизация частоты автосрабатывания (05.09.2026)

Тела скиллов, contract.md, схемы и шаблоны отчётов НЕ менялись. Изменены только
поверхности, по которым модель выбирает скилл.

1. `skills/*/SKILL.md` — `description` переписан по формуле «результат + 1B+ tracked
   Meta ads → Use when [намерения] → Also use when the user mentions [дословные фразы
   спроса] → директивный толчок → Not for [граница] (use сосед)». 858–997 симв.
   (лимит спецификации 1 024). Добавлено поле `when_to_use` с русскими триггерами
   (читает только Claude Code; суммарно ≤ 1 254 симв. при лимите листинга 1 536).
2. `manifest.json` — версия 1.0.3, описания равны тексту frontmatter (требование валидатора сервера).
3. `skills/*/agents/openai.yaml` — новые `display_name`, `short_description` (≤ 64
   символов), рабочий `default_prompt`, `allow_implicit_invocation: true` (в 1.0.2
   автовызов на Codex был полностью запрещён; включён решением владельца 05.09.2026).
   Откат — одна строка; защита от трат остаётся в contract.md (get_usage-префлайт,
   подтверждение платных вызовов, media off).

4. Редакция 05.09.2026: владелец снял запреты «spy»-лексики (ограничений платёжной
   системы и юридических нет) — в описания добавлены триггеры «facebook ads spy»,
   «ad spy», «spy on competitor ads», «store spy», «shop spy», «ads spy across pages»;
   в `when_to_use` — «спай…»-фразы и «espiar anuncios» (ES). Также добавлены
   мультиязычные триггеры PT/ES/JA из семантического ядра («biblioteca de anúncios»
   246 000/мес pt-BR).

Обоснование и источники: `research/skill-seo-2026-09/10-PLAN-I-REALIZACIYA.md`
и отчёты 01–04 в той же папке.
