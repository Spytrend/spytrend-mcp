# Contributing

This repository contains public connection metadata, documentation, examples, and workflow definitions for the hosted Spytrend MCP server. It does not contain the hosted server implementation.

## Changes

- Keep claims aligned with the live Spytrend MCP documentation.
- Do not add passwords, tokens, cookies, private URLs, customer data, or internal infrastructure details.
- Keep examples safe, minimal, and reproducible without real credentials.
- Preserve the distinction between archived data, live data, estimates, and unavailable values.
- Run link and JSON validation before opening a pull request.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
